# Teaser search and cited AI implementation plan

Goal: Real search and source interpretation in the existing private Hetzner web app.
Approach: Tavily basic search for URL discovery, existing robots/paywall-safe downloader
for original documents, OpenAI JSON planner/interpreter with literal citation validation.
Cited AI findings remain provisional and never upgrade a source to primary evidence.
No historical labels enter prompts; strict historical runs never call external APIs.

Files: api_budget.py (atomic persistent monthly reservations), external_research.py
(API contracts and citation validation), integration into config/main/investigation/web UI.
No new dependencies or services. Default off; credentials runtime-only; explicit API-cost
approval required. Monthly app reservation cap <= EUR20; documented provider billing caveats.

Tasks:
- Test budget concurrency/persistence and disabled/missing credentials without network.
- Test authenticated Tavily/OpenAI contracts and invalid citations/provider errors.
- Integrate teaser clues, global search, candidate identity and provisional evidence ranking.
- Test >=6 actually cited candidates plus contradictions, no solution leakage or gate weakening.
- Document exact Coolify setup, API usage, blocked live acceptance without keys.
- Full suite, Docker and review; separate PR; no remote deployment or merge.
